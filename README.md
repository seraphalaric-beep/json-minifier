# JSON Minifier Desktop App

This repository contains a simple Tkinter desktop app for minifying JSON. Paste JSON into the input area, click **Minify JSON**, then copy or save the compact output.

## Requirements

- Python 3.8 or newer.
- No extra dependencies are required beyond the standard library.

## Run the app

```bash
python main.py
```

## Usage

1. Paste or type JSON into the **Input JSON** panel or open a file with **Open File**.
2. Click **Minify JSON** (or press **Ctrl+M**).
3. Copy with **Copy Output** (**Ctrl+C**) or save the minified result with **Save Output** (**Ctrl+S**).
